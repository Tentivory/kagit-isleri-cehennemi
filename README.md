# Kağıt İşleri Cehennemi

## Resmi Proje Tanımı

Bu depo, insanlığın karşılaştığı en büyük varoluşsal tehditlerden birini bilimsel ciddiyette ele almaktadır: **Sonsuz Kağıt İşleri**. 

Her gün milyonlarca vatandaş, ofis koridorlarında kaybolmakta, damga peşinde koşmaktadır. Bu simülatör, o gerçeği dijital dünyaya taşır. **Gerçekten çalışır.** Bir kez başlattınız mı, süreç bitmez. Bitmemelidir. Bitmesi yasadışıdır.

### Özellikler
- Rastgele, ama son derece gerçekçi bürokratik adımlar üretir.
- Her adım sizi başlangıca daha yakın hissettirir.
- Tahmini süreler verir, gerçek süreyi sonsuz olarak sabitler.
- 8 adımda bir "ilerleme" bildirimi yapar (ilerleme yoktur).

### Nasıl Çalıştırılır?
```bash
python cehennem.py
```
Sonra oturun ve bekleyin. Beklemeyi sevin. Sevemezseniz de sorun değil, sistem umursamaz.

### Bilimsel Temel
Bu proje, "Bürokrasi Termodinamiği" adlı (var olmayan) bir teoriye dayanır. Entropi artar, evraklar çoğalır, çıkış azalır.

### Katkı
Pull request kabul edilir ama muhtemelen "eksik evrak" diye reddedilir. Issue açabilirsiniz, cevap süresi: sonsuz.
